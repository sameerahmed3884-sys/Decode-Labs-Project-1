# Classic Auto Care 🚗

A modern, responsive landing page for an automotive maintenance service, built as **Project 1** of the **DecodeLabs Industrial Training Kit**. This project demonstrates frontend development fundamentals, focusing on fluid typography, modern CSS layouts, and smooth user interactions.

## ✨ Features
* **Responsive Layout:** Built with CSS Grid and Flexbox for seamless viewing across all devices.
* **Modern UI/UX:** Features a glassmorphism navigation bar and hover animations on service cards.
* **Interactive Elements:** Smooth scrolling navigation and dynamic Call-to-Action (CTA) buttons using Vanilla JavaScript.
* **Scroll Animations:** Implemented `IntersectionObserver` for fade-in reveal effects as the user scrolls.

## 🛠️ Tech Stack
* **HTML5** (Semantic structure)
* **CSS3** (Custom properties, Grid, animations, media queries)
* **Vanilla JavaScript** (DOM manipulation, event listeners)
